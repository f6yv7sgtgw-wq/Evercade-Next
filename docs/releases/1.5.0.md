# Evercade Next 1.5.0

Status: **stable**

## Canonical release architecture

Evercade Next 1.5.0 is deployed directly from the files on `main`. There is no secondary `.release` source bundle, no materialization step and no generated source tree layered over the repository.

`VERSION.json` is the single version source. GitHub Pages validates the direct source, uploads that exact source tree and verifies the public deployment afterwards.

## GUI changes

- Cartridge packaging imagery for all 87 catalog entries through the compact 1.5 WebP sprite.
- Images are added to collection, catalog and Trefferzentrale cards.
- Collection cards are compact and do not expose Treffer/Details actions.
- The retired Fehlend/Wünsche counters remain hidden.
- Collection progress is reduced for mobile displays.
- `Vollsuche` is renamed to `Suche` in the visible navigation.
- Header, tabs, filters and card layouts are mobile optimized.
- Horizontal page scrolling is prevented.

## Search and Trefferzentrale retained from 1.4.7.3

- GenericParser 0.45.2 Build 6.
- 50 ms paid-worker pacing.
- Slash-safe search queries.
- One retry for HTTP 5xx after 5 seconds.
- Kleinanzeigen plus the nine automated retailer sources.
- Strict positive price normalization and cleanup of false zero-price offers.
- Ownership filter and best-offer ranking.
- Cross-platform guard against PlayStation, Xbox and Nintendo Switch false positives.

## Deployment

Workflow: `.github/workflows/pages.yml`

The workflow performs JavaScript syntax checks, runs `scripts/validate.mjs`, deploys the direct repository tree to GitHub Pages and verifies the public version and 1.5 UI markers.

# Evercade Next 1.4.5.9

## Purpose

This release targets the remaining reproducible HTTP 5xx failures seen on cartridge titles containing `/`, while tuning the full-search pacing for paid GenericParser Worker operation.

## Search-query normalization

The catalog and UI keep the original cartridge title unchanged. Only the query sent to GenericParser is normalized.

Examples:

- `Alwa’s Awakening / Cathedral` → `Evercade Alwa’s Awakening Cathedral`
- `Metal Dragon / Life on Mars` → `Evercade Metal Dragon Life on Mars`

Normalization replaces slash separators, including surrounding whitespace, with a single space and collapses repeated whitespace. Every changed query logs `parser.query.normalized` with the original title, normalized title, cartridge key, final query and reason `slash_removed`.

Direct source links retain the original title behavior; this fix is limited to the GenericParser request path that produced the reproducible 5xx failures.

## Paid-Worker pacing

- Inter-cartridge delay reduced from 200 ms to **50 ms**.
- Scheduled batch pauses remain disabled (`BATCH_DELAY_MS = 0`).
- Emergency Load-failure recovery remains available as a safety net.

## Existing reliability behavior retained

- GenericParser 0.45.2 Build 6 and `generic-parser-module-v1` are unchanged.
- A single HTTP 5xx retry after 5 seconds remains active.
- Detailed 5xx diagnostics retain response body, CF-Ray, request ID, Worker version and build.
- Persistent run diagnostics and request-rate telemetry remain active.

## Validation target

A clean validation should prove:

1. version `1.4.5.9` is canonical,
2. GenericParser Build 6 remains the expected backend,
3. `QUEUE_DELAY_MS = 50`,
4. slash-query normalization is present and logged,
5. no scheduled free-tier batch pause has returned.

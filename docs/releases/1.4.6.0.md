# Evercade Next 1.4.6.0

## Purpose

GUI cleanup before the next functional phase. Search behavior and GenericParser integration remain unchanged.

## Changes

- Header and main navigation are no longer sticky; scrolling content is no longer covered by the hanging header/navigation area.
- Visible navigation is reduced to **Sammlung**, **Katalog**, **Deals** and **Vollsuche**.
- **Fehlend** and **Wünsche** are removed from the visible GUI.
- Collection summary cards are reduced to **Sammlung** and **Kaufwert**.
- Wishlist buttons and the wishlist checkbox in cartridge details are hidden from the visible UI.
- The full-search description no longer references wishlist priority and now describes catalog-order processing.

## Compatibility

The internal collection state remains backward compatible. Existing local data is not deleted by this UI cleanup.

## Unchanged

- GenericParser 0.45.2 Build 6
- `generic-parser-module-v1`
- 50 ms paid-worker pacing
- HTTP 5xx retry behavior
- slash-safe query normalization
- diagnostics and event logging
- catalog data and owned-cartridge state

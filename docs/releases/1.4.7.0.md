# Evercade Next 1.4.7.0

## Phase 5.3 – Trefferzentrale

This release turns the former Deals view into a persistent offer center while keeping GenericParser 0.45.2 Build 6 and the proven search runtime unchanged.

## Central offer index

Every automatic search result is merged into a persistent `offerIndex` in local storage. Offers are de-duplicated primarily by source plus canonicalized URL. Existing `state.searches` data is retained for compatibility and migrated into the index when no index exists yet.

Each indexed offer stores the cartridge key/title/series/number, source, title, price, shipping, total price, URL, first-seen timestamp, last-seen timestamp, active/inactive state, and a bounded price-history list.

When a cartridge is searched again, its previously known offers are temporarily marked inactive. Offers returned again are reactivated and receive a new `lastSeen`. Previously known offers that are no longer returned remain in history as `Nicht mehr bestätigt` instead of disappearing silently.

## Trefferzentrale UI

The main navigation now exposes `Treffer` instead of the old Deals label. The page shows summary metrics for active offers, new offers, cartridges with active offers, and current best total price.

Filters are provided for active/new/all historical offers, source, maximum total price, and sorting by total price, newest offer, or cartridge. New offers remain marked until the user explicitly chooses `Neue als gesehen markieren`.

The existing single-cartridge search remains available below the center and updates the offer index immediately. Direct-source links remain available as a separate manual fallback.

## Full-search integration

The full-search queue writes every successful cartridge result directly into the Trefferzentrale. The existing 50 ms paid-Worker pacing, emergency recovery and GenericParser retry behavior remain unchanged.

## Mobile and overflow cleanup

Phase 5.3 is explicitly designed without horizontal page scrolling. Navigation uses a fixed four-column responsive grid rather than a horizontally scrolling tab row. Filter and metric grids use `minmax(0,1fr)`, long URLs/titles use wrapping, and `html, body` prevent horizontal overflow. On narrow screens the filter and metric grids collapse while preserving the four primary navigation actions within the viewport.

## Unchanged

- GenericParser 0.45.2 Build 6
- `generic-parser-module-v1`
- 87-entry Evercade catalog
- 50 ms inter-cartridge delay
- one 5-second retry for HTTP 5xx
- slash-safe search-query normalization
- diagnostics and event logging
- Fehlend/Wünsche remain removed from the visible GUI

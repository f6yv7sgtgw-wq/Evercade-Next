# Evercade Next 1.4.5.8

## Purpose

This release tunes Evercade Next for the paid GenericParser Worker and focuses on the remaining transient HTTP 5xx errors. The GenericParser search runtime itself remains unchanged at 0.45.2 Build 6.

## Paid-Worker pacing

- Reduce the inter-cartridge delay from 1500 ms to 200 ms.
- Disable the scheduled 30-second pause after each batch of 10 cartridges (`BATCH_DELAY_MS = 0`).
- Keep queue-delay telemetry so the configured and actual 200 ms pacing remains visible in the event log.
- Queue-delay events use the reason `paid_worker_pacing`.

## HTTP 5xx retry

For HTTP 5xx responses Evercade now performs one automatic retry after 5 seconds.

Retry sequence:

1. Record the failed HTTP response and its diagnostics.
2. Log `parser.retry.scheduled` with status, endpoint, query, request IDs and retry delay.
3. Wait 5000 ms; the wait remains abortable if the queue is paused.
4. Log `parser.retry.start` and repeat the same request once.
5. If the retry succeeds, log `parser.retry.recovered`.
6. If the retry also fails, continue with the existing fallback endpoint sequence.

## Extended 5xx diagnostics

For HTTP 5xx failures the log now records, where available:

- Cartridge query and endpoint
- HTTP status
- Retry attempt
- Cloudflare Ray ID (`cf-ray`)
- Worker request ID
- Worker version
- Worker build
- Response body
- JavaScript error name / constructor / stack
- Rolling Worker telemetry
- Total 5xx retries and recovered retries

## Emergency recovery

The previous free-tier scheduled batch pause is removed. The emergency recovery path remains as a safety net only if three consecutive `Load failed` requests occur:

1. Pause for 60 seconds.
2. Probe `/health`.
3. Resume when the Worker is healthy.
4. If health still fails, retry the health check every 15 seconds.

This path should normally remain inactive on the paid Worker.

## Constants

- Inter-cartridge delay: 200 ms
- Scheduled batch pause: disabled (0 ms)
- HTTP 5xx automatic retries: 1
- HTTP 5xx retry delay: 5000 ms
- Emergency recovery threshold: 3 consecutive `Load failed` requests
- Emergency recovery pause: 60000 ms
- Failed health-probe retry interval: 15000 ms

## Unchanged

- GenericParser: 0.45.2 Build 6
- Module contract: `generic-parser-module-v1`
- Search source and ranking behavior
- Catalog size and collection data model
